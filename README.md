# TwelveTwo Technology

Marketing site for TwelveTwo Technology, an independent software engineering firm.

```bash
npm install
npm run dev
```

The public site URL is `NEXT_PUBLIC_SITE_URL`. Project inquiries are sent by `POST /api/contact` through Resend. Set `RESEND_API_KEY` and `CONTACT_FROM_EMAIL` on Render. See `.env.example`. Do not put the Resend key in client code.
